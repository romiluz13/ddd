# Research archive

This directory preserves the broad Docs-Driven Development proposals that
predate the Proofline 0.4 kernel.

The material is not part of the supported product contract:

- `SPEC-0.3.md` is the superseded comprehensive methodology.
- `skills/` contains archived modeling, audit, tournament, refutation, control,
  and broad-drift workflows. Their entry files are named `SKILL.research.md` so
  skill registries do not install them.
- `plugins/artifact-registry.md` is experimental detector guidance.
- `artifacts/` contains archived object-passport and legacy exception schemas.

Use these files for design research only. Do not infer implemented CLI
capabilities or conformance requirements from them.
