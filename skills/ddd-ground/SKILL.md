# Ground the plan and implementation

Read [DDD](../ddd/SKILL.md) and apply **Ground the plan**, performing its
discovery first wherever sources or versions are missing. That skill owns the
procedure and Documentation basis format.

Finish a planning request with cited decisions, useful snippets labeled by
origin and execution status, checks to run, and open questions. Stop before
implementation when only a plan was requested.

For an authorized implementation, continue through DDD's **Implement with the
documentation** and **Compare the finished code and correct it**. Consult newly
introduced APIs before using them and maintain the existing plan. No claims,
packets, or trace ledgers are required.
