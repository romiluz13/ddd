# Discover the documentation

Read [DDD](../ddd/SKILL.md) and apply **Discover before planning** and its
Documentation basis rules. That skill owns the procedure.

Finish with touched APIs, resolved versions, relevant official sections,
constraints, and specific unresolved gaps. Investigate missing links
automatically. For discovery-only work, stop before planning or editing
application code. If the user authorized the whole task, continue through DDD.

Use [version detection](references/stack-detection.md) and
[source retrieval](references/adapters.md) when needed. No CLI setup is required.
